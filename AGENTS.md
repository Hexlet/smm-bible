# AGENTS.md

Сайт руководства на VitePress. Контент лежит в `docs/`, меню задаётся в `docs/.vitepress/config.mts`.

## Проверки

- `mise run check` запускает все обязательные проверки: rumdl, typos, jactionlint, проверку типов (tsc) и сборку сайта. Изменение не готово, пока эта команда не проходит. CI запускает ту же команду.
- `mise run fix` применяет безопасные автоисправления.
- `mise run links` проверяет внешние ссылки. Ему нужна сеть, в CI он идёт отдельным workflow.

## Правила

- Правила линтеров не отключаются, чтобы провести изменение. Исключение должно быть узким (один путь и одно правило), с причиной в комментарии, и его принимает человек.
- `docs/.vitepress/dist` и `docs/.vitepress/cache` генерируются сборкой и не редактируются руками.
- Новая страница добавляется в `sidebar` в `docs/.vitepress/config.mts`, иначе её не найти в меню.
