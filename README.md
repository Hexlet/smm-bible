# SMM Bible

Практическое руководство по SMM. Сайт собирается на [VitePress](https://vitepress.dev) и публикуется на GitHub Pages.

## Локальный запуск

```sh
npm install
npm run dev
```

## Как добавить страницу

1. Создайте `.md`-файл в нужном разделе внутри `docs/`.
2. Добавьте ссылку на него в `sidebar` в `docs/.vitepress/config.mts`.
