# Площадки

Справочник соцсетей, мессенджеров и контентных площадок. Для каждой соцсети есть обзор её роли, возможностей и аналитики, а также отдельная инструкция по публикации и сопровождению: оформление, настройки, выпуск, анонсы, закрепы, ответы и обновление материалов.

## Где возникает органическое обнаружение

Органика включает и контакты с подписчиками, и знакомство новых людей с автором без покупки конкретного размещения. Для роста важно второе: какой путь способен вывести материал за пределы своей базы. Сначала разберите [ситуации потребления](/strategy/content-consumption), затем сопоставьте доступные маршруты.

| Площадка | Первое знакомство без подписки | Как возвращаются | Существенное условие |
| --- | --- | --- | --- |
| [Telegram](/platforms/telegram) | Пересылки, похожие публичные каналы, поиск каналов и постов | Канал, подписка, уведомления, сохранённая ссылка | У глобального полнотекстового поиска есть условия доступа и квоты; подборка рекомендует канал, а не каждый его пост |
| [VK](/platforms/vk) | Рекомендации оригинальных материалов, действия знакомых, репосты | Сообщество, подписка | Рекомендательный показ и чтение своей базы учитывают отдельно; поиск записей здесь отдельно не сверён |
| [VK Видео](/platforms/vk-video) | Поиск, рекомендации, связанный клип, внешний анонс | Подписки, канал, плейлист, продолжение просмотра | Поиск и внешнее распространение нужно различать в источниках трафика |
| [VK Клипы](/platforms/vk-clips) | Рекомендательная лента, тренды, реакции друзей | Подписки, профиль, серия | Поиск именно клипов отдельно не сверён; возможности длинных видео нельзя автоматически переносить на короткие |
| [YouTube](/platforms/youtube) | Поиск, главная, следующие видео, Shorts, внешняя ссылка | Подписки, канал, серии, уведомления | Уведомление не гарантировано на каждый выпуск; рекомендации и поиск решают разные задачи |
| [Instagram](/platforms/instagram) | Reels, Explore, рекомендации в ленте, поиск, пересылки и репосты | Подписки, профиль, Stories | Разрешённая публикация может не допускаться к рекомендациям; режимы и ограничения проверяют для аккаунта |
| [TikTok](/platforms/tiktok) | For You, поиск, пересылки | Following, профиль | Following тоже персонализируется; публикация в аккаунте не гарантирует допуск в For You |
| [Threads](/platforms/threads) | For You, темы, поиск, ответы, цитаты, репосты; рекомендации подходящих постов в других приложениях Meta | Following, профиль, продолжение разговора | Межсервисные рекомендации и отдельные способы участия доступны не для каждого материала |
| [X / Twitter](/platforms/twitter) | For You, поиск, темы, репосты и обсуждения | Following, профиль, закладки | Приватность, допуск к рекомендациям и настройки поиска ограничивают обнаружение |
| [MAX](/platforms/max) | Поиск публичного канала, приглашения, объявленная лента рекомендаций, репост поста в историю на Android | Подписка, список чатов, уведомления | Критерии рекомендаций и полнотекстовый поиск постов отдельно не подтверждены; проверяйте доступный маршрут в клиенте |
| [Одноклассники](/platforms/ok) | Рекомендации, поиск группы, «Классы» знакомых, передача поста | Лента друзей и групп, группа | «Класс» создаёт возможность распространения друзьям, но не гарантирует показ каждому; по словам ОК, внешние ссылки снижают показы в рекомендациях |
| [Дзен](/platforms/dzen) | Рекомендательные ленты статей и видео, внешняя ссылка | Подписки, канал, связанные материалы | Материал, не соответствующий требованиям (кликбейт, заимствование, спам), рекомендуется только подписчикам; внутренний поиск отдельно не сверен |
| [RUTUBE](/platforms/rutube) | Поиск, персональная лента, пересланная ссылка | Подписки, история, плейлисты, «Смотреть позже» | Видео «Только по ссылке» исключено из поиска, но ссылка может передаваться дальше |
| [Pinterest](/platforms/pinterest) | Поиск, главная, похожие идеи, публичные доски и отправка пина | Сохранённые пины, доски, профиль | Закрытые доски не работают как публичные подборки; сохранение и переход на сайт — разные действия |
| [TenChat](/platforms/tenchat) | Рекомендательная лента, поиск публикаций и хештегов, профессиональные связи | Подписки, связи, сохранённые подборки | Наличие рекомендательного механизма и отметки поста не устанавливает охват или поток клиентов |
| [Сетка](/platforms/setka) | Рекомендации, профессиональные сетки, вопросы, тренды, поиск профилей и сообществ | Подписки по новизне, профиль, сообщества | Канал может быть скрыт из поиска и рекомендаций; поиск текста обычных постов отдельно не подтверждён |
| [Facebook](/platforms/facebook) | Рекомендации, поиск, публичные обсуждения и передача публикаций | Люди, страницы, группы, подписки | Настройки аудитории и приватности задают, кому материал вообще доступен |
| [LinkedIn](/platforms/linkedin) | Рекомендации вне сети, поиск, профессиональные обсуждения | Подписки на автора, компанию, рассылку | Пост только для контактов не становится публичным из-за взаимодействий |

Маршруты сверены с официальными описаниями 21 ноября 2026 года, условия для Одноклассников и Дзена — 22 ноября; основания и ограничения приведены в обзорах. «Не сверено» означает пробел проверки, а не отсутствие функции. Таблица не ранжирует площадки по силе органики: результат зависит от темы, формата, аудитории и условий доступа. Для проекта выберите конкретный маршрут и проверьте его по доступным источникам трафика, новым читателям и возвращениям.
