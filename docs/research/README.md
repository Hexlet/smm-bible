## Как использовать источники при правке

За существенным фактическим утверждением хранить конкретный источник, подтверждаемый тезис, дату проверки и ограничения. Для рекомендации дополнительно указывать условия применения. Ссылка на весь сайт не заменяет ссылку на документ или материал, подтверждающий тезис.

Например, формулировку «карусели эффективнее видео» нужно уточнять: на какой площадке, для какого показателя, в какой выборке и за какой период. Связь с вовлечённостью нельзя автоматически выдавать за влияние на продажи.

Рабочая карточка для подготовки или проверки главы:

| Поле | Что записать |
| --- | --- |
| Глава | Путь к материалу руководства |
| Тезис | Конкретное утверждение или рекомендация |
| Источник | Название, автор или организация, прямая ссылка |
| Основание | Раздел, страница, таблица или данные, подтверждающие тезис |
| Даты | Дата публикации, период данных и дата нашей проверки |
| Тип материала | Исследование, наблюдение, метод автора, документация или кейс |
| Ограничения | География, выборка, метод, версия продукта и условия применения |
| Решение | Что подтвердили, уточнили, удалили или оставили для проверки |

Не представлять метод автора как установленную закономерность, наблюдаемую связь как доказанную причину, а учебный пример как реальный кейс. Если подтверждения нет, уточнить формулировку, явно обозначить гипотезу или убрать утверждение.

Для инструкций по площадкам и правовым требованиям указывать дату проверки в соответствующей главе и перепроверять источник перед обновлением. Подборка задаёт направления работы; она не означает, что все главы уже прошли сверку.
