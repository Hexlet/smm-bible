## Telegram: комментарии к постам каналов

Прочитаны 21.11.2026, явной даты редакции нет; страница метода показывает слой схемы 225.

- Telegram, [Message threads](https://core.telegram.org/api/threads): комментирование постов канала реализовано через ветки сообщений; ответы на сообщение с ID 420 относятся к ветке 420.
- Telegram, [Discussion groups](https://core.telegram.org/api/discussion): группа подключается к каналу как группа обсуждения; «The comment section of a channel post is simply the message thread of the automatically forwarded channel message in the linked discussion supergroup». Пользователь может комментировать, не вступая в группу. Удаление пересланной копии поста отключает комментарии к нему.
- Telegram, [messages.getDiscussionMessage](https://core.telegram.org/method/messages.getDiscussionMessage), слой 225: получает сообщение обсуждения из связанной группы «without actually joining the group»; «Only users can use this method».
- Telegram, [messages.getReplies](https://core.telegram.org/method/messages.getReplies), слой 225: «Get messages in a reply thread»; «Only users can use this method». Параметры `offset_id`, `offset_date`, `add_offset`, `limit`, `max_id`, `min_id` отвечают за постраничную выдачу.
- Telegram, [Pagination in the API](https://core.telegram.org/api/offsets): большие списки требуют постраничной выдачи; `limit` обычно от 1 до 100.

**Граница.** Документация прямо не называет, какие `peer` и `msg_id` передавать в `messages.getReplies` для комментариев к посту канала. По описанию ветки это, вероятно, группа обсуждения и ID пересланной копии поста, но это вывод, поэтому в главе параметры не указаны. Выгрузка не запускалась. Квоты, ограничения частоты для пользовательских клиентов и условия использования Telegram для автоматического сбора не проверялись.

## Что проверить не удалось

- **Документация VK API** (`dev.vk.com`, методы комментариев к записям и видео, типы ключей доступа): веб-инструмент получил отказ, загрузка через curl в этой сессии не разрешена. Поэтому в главе нет названий методов VK; текст направляет к официальной документации и выгрузкам систем мониторинга.
- **Официальное заявление TikTok об ограничении сервиса в России (март 2022 года)**: страница рассылки новостей TikTok по проверенному адресу показала главную, публикация в X недоступна (HTTP 402), справка о поддерживаемых странах Ads Manager удалена. Утверждение об ограничении загрузки в России в главу не вносилось; вместо него — нейтральная оговорка о том, что подборка не подтверждает актуальность для российской аудитории.
- **Замедление YouTube, доля Яндекса в поиске, доступность зарубежных AI-моделей и Google Cloud из России, судебная практика о парсинге**: первоисточники не искались, в текст глав не вносились.
